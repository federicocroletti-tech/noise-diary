# Segnalazioni di sicurezza e privacy

Non pubblicare vulnerabilità, dati personali, registrazioni o documenti di casi in issue o pull request pubbliche.

Per inviare una segnalazione privata, usa il canale **Report a vulnerability** di GitHub Security Advisories se abilitato per il repository. Se non è disponibile, contatta il maintainer tramite i canali privati indicati nel profilo GitHub del repository. Non allegare dati reali non necessari.

Descrivi versione o commit, impatto, passaggi minimi riproducibili e un modo sicuro per ricontattarti. La segnalazione sarà valutata prima della divulgazione pubblica; non è garantita una tempistica di risposta.

Il progetto non può offrire un servizio di risposta alle emergenze. In caso di pericolo imminente, usa i servizi locali competenti.
