# Giurisdizioni

Le guide operative condivise e non giuridiche si trovano in [`global/`](./global/README.md). Le procedure di un Paese non devono essere riutilizzate come se valessero altrove.

Non sono ancora pubblicate guide nazionali verificate. Una nuova giurisdizione può essere aggiunta solo con fonti ufficiali, data di verifica, revisore e ambito territoriale espliciti.
