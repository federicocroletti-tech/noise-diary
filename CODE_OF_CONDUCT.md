# Codice di condotta

Vogliamo un ambiente collaborativo, rispettoso e accessibile. Sono richiesti rispetto, chiarezza e buona fede; non sono ammessi molestie, discriminazioni, minacce, doxxing, attacchi personali o pubblicazione intenzionale di dati privati.

Critica le idee e le fonti, non le persone. Considera con attenzione le correzioni e comunica i disaccordi senza intimidazioni. Non usare il repository per promozioni non pertinenti o per presentare ipotesi come fatti.

Per segnalare un problema di condotta, contatta privatamente il maintainer tramite i canali indicati nel profilo GitHub del repository. Non pubblicare informazioni personali nel report. Il maintainer valuterà la segnalazione e potrà moderare, modificare o rifiutare contributi; la decisione finale è sua.

Il codice di condotta riguarda gli spazi del progetto e non sostituisce le regole o le procedure degli enti competenti.
