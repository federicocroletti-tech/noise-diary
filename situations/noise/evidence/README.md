# Prove ed evidenze

Raccogli solo ciò che è sicuro, pertinente e consentito. Un file documenta un'acquisizione; non prova automaticamente origine, responsabilità o livello sonoro.

- [Checklist](./evidence-checklist.md)
- [Registro eventi](./event-log-template.md)
- [Indicazioni per le foto](./photo-guidelines.md)
- [Indicazioni per l'audio](./audio-guidelines.md)

Conserva gli originali in un luogo sicuro, annota provenienza e orario e separa osservazioni, ipotesi e valutazioni. Prima di condividere, verifica privacy, consenso e regole locali.
