# Autorità e servizi potenzialmente pertinenti

Non è stata verificata né indicata un'autorità competente per una specifica giurisdizione. Le competenze variano per luogo, tipo di rumore e circostanze. Consulta la matrice solo per registrare una verifica svolta su fonti ufficiali; non considerarla un elenco di destinatari.

Per un pericolo immediato, contatta i servizi di emergenza locali. Non attendere la compilazione di questo fascicolo.
